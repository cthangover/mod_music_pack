# Music Pack — музыка для вашей игры

**22 музыкальные композиции** для исследования мира, сражений и главного меню. Набор можно использовать в разных играх на cthangover, не копируя музыку в каждый сюжетный мод.

![Три музыкальных контекста: исследование, бой и главное меню](assets/playlists.png)

## Что услышит игрок

- **Исследование мира:** 8 композиций для сцен без собственного плейлиста, в том числе RPG-карт.
- **Сражения:** 12 композиций в плейлисте `Battle`. В запасном боевом списке `default` также есть `Empty Save Room` — всего 13.
- **Главное меню:** `Serpent's Lament`.

> Music Pack содержит музыку и плейлисты. Новых локаций, заданий и игровых механик он не добавляет.

## Нужно ли что-то настраивать

Если ваша игра уже использует Music Pack, устанавливать отдельные треки или выбирать их вручную не требуется. Музыку воспроизводит система `audio_base`.

Набор используется главным меню, Cthangover, шаблоном новеллы и RPG-играми проекта. Он не требует загрузки сюжета основной игры.

## Подключение к своей игре

1. Установите `music_pack` и его зависимость `audio_base`.
2. В `manifest.json` своего контентного мода добавьте зависимость `music_pack>=1` к уже существующему списку `depends`.
3. Для сцен без особых требований используйте готовые плейлисты. Для собственной подборки добавьте JSON-файл в `music/playlists/` вашего мода.

Пример зависимости:

```jsonc
// Добавьте зависимость к существующему списку:
"depends": ["music_pack>=1"]
```

Пример размещения собственного плейлиста:

```filestree
my_game/
├── manifest.json
└── music/
    └── playlists/
        └── my_scene.json  # Музыка вашей сцены
```

Пример собственного плейлиста для сцены `my_scene`:

```json
{
  "Scene": "my_scene",
  "Musics": [
    {
      "MusicType": "Ambient",
      "MusicNames": ["Airborne Melody", "Twilight Interlude"]
    }
  ]
}
```

Имена композиций указываются **без расширения `.ogg`**, с точным регистром и пробелами. Вместо `my_scene` укажите имя своей сцены.

## Какие плейлисты входят

- `default` — музыка исследования (`Ambient`) и запасная музыка боя (`Combat`).
- `Battle` — боевая музыка для обеих боевых систем.
- `MainMenu` — тема главного меню.

Плейлист `town_entry` принадлежит сюжетному моду `cthangover_game` и в этот набор не входит.

## Если музыка не играет

- Проверьте, что `music_pack` и `audio_base` установлены и включены.
- Проверьте громкость музыки в настройках игры.
- Если проблема только в одной сцене, проверьте её собственный плейлист и точные имена треков.
- Более поздний зависимый мод может заменить музыкальную подборку для той же сцены и типа музыки.
